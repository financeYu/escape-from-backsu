# Short Handoff Template

Use this short form for Level 1 or docs-only changes that do not touch runtime
behavior, contracts, schemas, generated-output boundaries, roadmap verdicts,
score/ranking/report/backtest semantics, valuation activation, or data
ingestion.

Use the full `docs/master_up_template.md` instead for Step-end work, Level 3
work, failed validation with boundary risk, cross-project handoffs, or any
change that triggers scope watchdog, Cross-Step Conflict Checkpoint,
`review_mvp`, or root-agent conflict stop requirements.

```text
[Short handoff]
- scope:
- changed files:
- validation:
- generated outputs/cache boundary:
- hard-stop check:
- archive/history read: yes/no; reason:
- remaining risk:
- review_mvp required: yes/no; reason:
- status: COMPLETE / PARTIALLY COMPLETE / NEEDS FIX
```
