# Archive Index

This index is a routing aid for historical roadmap, checklist, Step planning,
validation, and release-reference files. It does not replace `AGENTS.md`,
`docs/roadmap_status.md`, `docs/context/MVP_V0_1_BASELINE.md`, or active task
instructions.

## Purpose

Use this file to find old planning and validation material only when a current
task has a named reason to inspect history. The default working context after
MVP v0.1 freeze should stay focused on the active baseline, contract/routing
manifests, extension registry, change-impact routing, and task-specific files.

## Archive-Only Rule

Files listed below are historical references only unless another active
authority document explicitly names a narrow lookup reason. They are not active
implementation instructions, not the active roadmap, and not required default
context for future agents.

Do not import old Step history into active GPT/Codex context by default.

## Lookup Rules

Open archive files only for:

1. regression investigation
2. provenance/source confirmation
3. release/freeze verification
4. resolving a contradiction with the MVP v0.1 baseline

When a lookup is needed, open the narrowest file and section that answers the
question. Prefer path references and short purpose notes over copying old
document bodies into active context.
