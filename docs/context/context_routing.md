# Context Routing Matrix

This matrix is a routing aid, not an authority document. It helps workers pick
the smallest useful context set before starting a task. It does not override
`AGENTS.md`, `docs/project_checklist.md`, `docs/roadmap_status.md`, the active
`WORKSPACE_MANIFEST.md`, or the user's latest instruction.

Workers must not freely decide to read the entire repository. Start from the
default-read files named in `docs/context/current_context.md`, then add only the
task-specific files below. Use targeted search only when a direct conflict,
missing contract, or unclear boundary is found.

Archive/history files are never default context. Read archive files only for a
named conflict, regression, provenance check, or missing evidence item.
